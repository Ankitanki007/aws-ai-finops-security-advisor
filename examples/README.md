# Example Report

`sample-report.json` is a synthetic example of the scanner's report format.
The account ID is a placeholder. This file is not evidence of a live
account's configuration.

The example demonstrates a security finding and the fallback behavior
when optional Bedrock inference is unavailable.

Actual deployment testing produced S3 reports successfully.
Bedrock inference verification remains pending because the account's
applied Nova Micro inference quotas were zero.
